# Slack Business — 사업개발·서비스·고객 확장

Slack 사업에서 고객의 요구를 라이선스 제안, 온보딩·교육·이관 서비스와 후속 기회로 연결했습니다. 제안부터 수행, 사용 점검, 갱신·확장까지의 담당 경험과 그 근거가 되는 자료를 정리했습니다.

**먼저 볼 내용: [Slack 사업개발 — 사내 도입에서 서비스·고객 확장까지](business-development.md)**

## 사업을 전개한 흐름

| 단계 | 담당한 활동 | 관련 사례 |
|---|---|---|
| 사업 시작 | 사내 도입 제안·내부 PM, 이후 고객 대상 사업 전개 | [사업개발 상세](business-development.md) |
| 제안과 서비스 구성 | 고객의 도입 조건에 맞춰 라이선스·교육·온보딩·이관 범위 구체화 | [고객 피드백에 따른 제안 조정](../../case-studies/12-feedback-led-proposal.md) |
| 고객 도입과 수행 | 단계별 온보딩·교육, 이관과 기술 이슈 조율 | [온보딩](../../case-studies/07-phased-onboarding.md) · [이관](../../case-studies/02-large-scale-migration.md) |
| 유지와 확장 | 사용 결과 점검, 갱신 지원, 교육 접점의 후속 PoC·제안 | [계약·갱신](../../case-studies/10-trial-and-renewal.md) · [확장 기회](../../case-studies/08-account-expansion.md) |

## 읽는 기준

원본의 구성과 담당 역할을 확인한 뒤 고객·계정·계약 정보를 제거하고 공개용으로 다시 작성했습니다. 회사 공동 자료의 기여 범위, 제안·초안과 수행 결과는 각 문서에 표시했습니다. 새로운 예시나 문서 틀로 재구성한 부분은 실제 고객에게 납품한 원본과 구분합니다.

*자료 기준: 2023–2026년 사업·제안·수행 자료 · 정리일: 2026-10-07*

CRM 제안 경험은 [CRM 고객 생애주기 제안](../crm-customer-lifecycle.md)에서 볼 수 있습니다. 고객 요건과 내부 승인, 기술·수행팀 협업, 성공계획과 확장 흐름을 연결한 2023년 공동 제안 사례입니다.
