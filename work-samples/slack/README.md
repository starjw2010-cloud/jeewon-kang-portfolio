# Slack — 고객 도입·교육·운영 자료 모음

Slack 컨설팅 과정에서 작성·구성한 자료를 바탕으로, 고객의 질문을 교육·작업 계획·운영 문서로 바꾸는 방식을 정리했습니다. 산출물마다 목적, 설계 판단과 구체적인 예시를 볼 수 있습니다.

## 읽는 기준

원본의 구성과 담당 역할을 확인한 뒤 고객·계정·계약 정보를 제거하고 공개용으로 다시 작성했습니다. 회사 공동 자료의 기여 범위, 제안·초안과 수행 결과는 각 문서에 표시했습니다. 새로운 예시나 문서 틀로 재구성한 부분은 실제 고객에게 납품한 원본과 구분합니다.
