# Slack — Solution Design, Enablement & Operating Materials

Slack 도입을 지원하며 작성·구성한 교육, 서비스 소개, 연동 가이드와 제안 자료에서 업무 접근 방식을 정리했습니다. 회사 공동 자료는 기존 담당 경력과 함께 해석하며, 자료에 담긴 제안 범위와 실제 수행 결과를 구분합니다.

**자료 기준:** 2025–2026년 교육·온보딩·제안·기술 설명 자료 · **검토일:** 2026-10-07

[Slack 자료 모음](slack/README.md)에서 역할별 교육, 이관 준비, 기술·사용자 안내와 집필·도식 설계의 상세 샘플을 볼 수 있습니다.

## 1. 도입 이후까지 이어지는 서비스 설계

온보딩·확장 패키지와 후속 운영지원 자료에서는 초기 사용, 복수 조직 확산, 전사 운영을 구분했습니다. 교육뿐 아니라 이관 준비, 정책 설계, 사용자 안내와 관리자 인계를 제공 범위에 포함했습니다.

| 도입 단계 | 설계한 업무와 산출물 |
|---|---|
| 초기 정착 | 협업 구조 확인, 채널 설계, 사용자·관리자 교육, 온보딩 가이드 |
| 조직 확산 | 여러 부서의 운영 정책, 이관 계획, 사용자 커뮤니케이션, 검수 항목 |
| 운영 전환 | 관리자 역할, 접근·앱 정책, 운영 플레이북과 지식 이전 |
| 후속 지원 | 계정·앱·채널 점검, 설정 변경 검토, 기술지원 연결과 개선 권고 |

이는 서비스 구성과 제공 범위를 설명한 자료입니다. 소개서의 모든 항목을 모든 고객에게 납품했다는 의미는 아닙니다. 개별 프로젝트의 실제 결과는 [고객 사례](../README.md#selected-case-studies)에 정리했습니다.

## 2. 교육 이후에 남길 운영 자산

유통기업 대상 교육 제안에서는 일반 사용자와 관리자 과정을 나누고, 교육 후에도 참고할 자료를 산출물로 제시했습니다.

- 사용자를 위한 협업·검색·문서화·Workflow 실습과 사용 가이드
- 관리자를 위한 권한·입퇴사·채널 정책·앱 승인·보안 점검 내용
- 운영 정책서, 관리자 체크리스트, 실습지와 후속 참고자료

해당 제안에는 강지원이 담당자로 명시되어 있습니다. 여기서 확인되는 성과는 역할별 교육과 운영 자산의 설계이며, 각 산출물의 납품·활용 효과는 별도 수행 근거로 확인합니다.

## 3. 고객 업무를 역할별 실습으로 전환

교원 연수용 자료에서는 가상 대학의 학생·운영자·의사결정자 역할을 바꾸며 업무를 경험하도록 실습을 구성했습니다.

```text
상담 요청 접수와 담당자 배정
→ 비교과 프로그램 제안과 승인
→ 업무 기록과 진행 상황 정리
→ 의사결정자를 위한 브리핑과 AI 요약
```

기능 설명을 실제 역할과 업무 순서에 연결한 교육 시나리오입니다. 가상 환경의 실습 설계로 설명하며 실제 대학 운영 시스템 구축이나 생산성 효과로 확대하지 않습니다.

다른 대학 온보딩 자료는 고객의 질문인 현황 취합, 신규 구성원 정착과 기존 도구 연결을 중심으로 구성했습니다. 기본 기능으로 설명할 수 있는 영역과 외부 도구·별도 구현이 필요한 과제를 나누어 다음 논의를 준비했습니다.

## 4. 기술·보안 자료를 실행 가능한 설명으로 구성

Salesforce·Slack 연동 가이드와 영업 활용 설정 가이드는 선행 조건, 관리자별 역할, 사용자 연결·권한, 확인과 문제 해결 순서로 구성했습니다. 여러 담당자가 참여하는 작업에서 누가 무엇을 먼저 확인해야 하는지 설명하는 문서화 경험입니다.

보안 자료에서는 기존 문서 보안과 협업 플랫폼의 보호 대상을 나누고, 접근 권한·데이터 취급·앱 연결을 검토 항목으로 정리했습니다. 여기서는 요구사항을 설명한 역량을 다룹니다. 과거 자료의 기능표나 제안 아키텍처를 현재 제품 사양·보안 보증으로 재게시하지 않습니다.

## 5. 대외 콘텐츠로 정리한 정착 관점

웨비나 준비 자료에서는 도입 조직의 설득, 기존 시스템과의 역할 분담, 협업 규칙과 지속 운영을 주제로 구성했습니다. 경영진, IT 담당자와 현업이 각각 확인할 근거를 나누어 설명하는 접근입니다.

검토한 자료는 일부 화면·사례를 채울 항목이 남은 발표 초안입니다. 콘텐츠 기획 근거로 활용하며 행사 완료·참석자 수·교육 효과는 주장하지 않습니다.
