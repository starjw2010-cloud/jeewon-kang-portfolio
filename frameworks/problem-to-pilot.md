# Problem to Pilot Framework

## 1. Problem
- 누가 불편한가?
- 어떤 업무가 느리거나 반복되는가?
- 오류나 리스크는 무엇인가?

## 2. Constraint
- 데이터
- 보안
- 권한
- 일정
- 예산
- 사용자 수준

## 3. Candidate
- 프로세스 변경
- SaaS 설정
- Workflow 자동화
- AI
- 별도 개발

AI가 항상 답은 아닙니다.

## 4. Success Criteria
Pilot 전에 종료 기준을 정합니다.

- 사용 가능한가
- 정확한가
- 안전한가
- 시간이 줄었는가
- 사용자가 계속 쓰는가

## 5. Pilot
작은 범위에서 실제 사용자·데이터와 최대한 비슷한 조건으로 테스트합니다.

## 6. Decision
- Scale
- Revise
- Hold
- Stop
