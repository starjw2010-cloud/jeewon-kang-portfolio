# 프리세일즈·솔루션 컨설팅

고객의 업무 문제와 구매·운영 조건을 확인하고, 이를 제안·데모·PoC로 구체화합니다. 서비스 패키지와 실제 도입 경험을 함께 활용해 고객에게 제공할 범위와 기술 검증 조건을 설명합니다.

## 대표 사례

1. [GS AI 앱·프로토타입](../case-studies/14-gs-ai-intelligence-prototypes.md): 산업별 정보를 업무 시나리오와 시연 환경으로 구체화
2. [Enterprise PoC](../case-studies/01-enterprise-poc-security.md): 고객·IT·보안 요구를 검증 범위와 조치로 연결
3. [고객 피드백 기반 제안](../case-studies/12-feedback-led-proposal.md): 고객의 추진 범위와 우선순위에 맞춰 제안 수정
4. [서비스 패키지](../case-studies/15-service-business-model.md): 기능 소개를 서비스 구성과 구매 범위로 연결

## 면접에서 설명할 판단

어떤 문제를 시연할지, 무엇을 실제 검증할지, 어떤 연동·권한 조건을 선행 확인할지, 고객이 다음 단계로 넘어갈 판단 기준은 무엇인지 설명합니다. 데모 완성·실제 시연·PoC·수주는 각각 결과를 구분합니다.

## 지원 전 확인

기술직 공고가 요구하는 직접 코딩·아키텍처·성능·클라우드 운영 경험은 프로토타입 보유만으로 충족했다고 판단하지 않습니다. 본인이 설명하고 재현할 수 있는 범위와 AI-assisted 구현 범위를 함께 제시합니다.
