# How I Work

```text
Understand the Problem
        ↓
Define Scope & Success Criteria
        ↓
Design the Workflow / Program / PoC
        ↓
Build or Configure
        ↓
Test with Users / Data
        ↓
Measure & Review
        ↓
Expand, Revise or Stop
```

중요하게 보는 것은 새로운 기술을 많이 넣는 것이 아니라 **문제가 무엇인지, 사용자가 실제로 쓸 수 있는지, 결과를 어떻게 확인할지**입니다.

AI는 결과물을 대신 책임지는 도구보다, 조사와 구현 속도를 높이는 작업 도구로 사용합니다.

ChatGPT / Claude

- 사실 확인

AI가 생성한 코드와 직접 수기 코딩을 동일하게 표현하지 않습니다.

# Working Principles

1. **문제를 기능보다 먼저 봅니다.**
2. **Pilot의 성공을 반드시 계약으로 정의하지 않습니다.**
3. **모르는 것과 확인되지 않은 것을 구분합니다.**
4. **기술의 가능성과 실제 운영 가능성을 따로 봅니다.**
5. **반복되는 문제는 문서·프로세스·자동화로 줄입니다.**
