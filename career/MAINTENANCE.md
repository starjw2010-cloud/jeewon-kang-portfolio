# 경력 자료 갱신과 인수인계

## 현재 기준

2026-10-09 업데이트: 기존 Customer Success·SaaS 수행 사례를 유지하고 사업개발·상품기획·파트너 공동 사업 경험을 추가했습니다. AI-assisted 구현과 고객 사업 경험은 연결하되 프로젝트의 실제 상태는 분리했습니다.

## 새 정보가 생기면

1. [사례 템플릿](../templates/experience-card.md)에 기간·문제·본인 역할·결정·산출물·결과를 입력합니다.
2. 근거의 원문을 읽었는지, 사용자 설명인지, 해석인지 표시합니다.
3. [근거표](EVIDENCE_REGISTER.md)에 ID와 확인 상태를 반영합니다.
4. 사실이 달라진 사례 문서와 [통합 원장](MASTER_PROFILE.md)을 수정합니다.
5. 해당 직무 트랙과 지원 문장을 갱신합니다.
6. 날짜·변경 이유·정정 내용을 Git commit에 남깁니다.

단순 새 대화 요약을 기존 문서에 계속 덧붙이기보다 동일한 사례를 수정합니다. 정정된 과거 표현은 근거표에 이유를 남겨 다시 되살아나지 않게 합니다.

## 공개본과 비공개본

공개본은 역량·판단·산출물·일반화된 사례를 제공합니다. 비공개본에는 원문 링크·견적·계약·담당자·지원현황 등을 관리합니다. 기존 Google Drive의 자료를 이동하거나 공유 범위를 바꾸지 않습니다. 현재는 자동 동기화가 없으므로 갱신 일자와 버전을 수동으로 대조합니다.
