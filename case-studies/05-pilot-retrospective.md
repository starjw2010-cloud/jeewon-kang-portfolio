# Case 05. Pilot Retrospective

## Situation
기업 고객의 4개월 Pilot을 운영하면서 온보딩·교육 이후 실제 사용 수준을 확인했습니다.

## Evidence
- 활성 사용자
- 메시지 사용량
- 파일 공유량
- 사용자 참여

기대보다 Adoption이 낮았고 고객은 기존 협업 도구 중심 운영을 유지하기로 결정했습니다.

## Response
도입 성공 사례처럼 포장하지 않고 실제 사용 데이터를 바탕으로:

- 사용된 영역
- 참여가 낮은 영역
- 기존 환경의 영향
- 미도입 판단 이유

를 구분해 정리했습니다.

## Lesson
Pilot의 목적은 계약 전환 하나가 아니라, 고객이 **도입·보류·중단을 근거 있게 결정하도록 돕는 것**이라고 생각합니다.
