# Case 04. Needs → Program → Feedback

## Situation
서로 다른 경험 수준을 가진 참가자를 대상으로 3일 교육 프로그램을 운영해야 했습니다.

## Approach
교육 전 사전 설문으로 다음을 확인했습니다.

- 기존 사용 경험
- 역할
- 관심 기능
- 어려운 업무
- 기대 주제

결과를 바탕으로 커리큘럼과 실습 난이도를 조정했습니다.

## Result
교육 후 만족도는 **86%**였습니다.

## Lesson
고객이 요청한 교육 제목만으로 커리큘럼을 만들기보다, 실제 학습 대상과 교육 이후의 행동 목표를 먼저 확인하는 편이 프로그램 품질을 높였습니다.
