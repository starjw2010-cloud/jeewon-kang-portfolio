# Case 04. Needs → Program → Feedback

**고객:** 대학 · **기간:** 2026.06 · **상태:** 3일 컨설팅·교육 수행 완료

## Situation

관리자와 교직원의 사용 경험과 관심 주제가 달라, 동일한 기능 설명만으로는 각자의 업무에 적용하기 어려웠습니다.

## My Role

사전 설문, 커리큘럼 구성, 강의·실습과 피드백 수집을 담당했습니다.

## Action

- 사전 설문으로 기존 사용 경험, 역할, 관심 기능, 어려운 업무와 기대 주제를 확인했습니다.
- 관리자와 일반 사용자에게 필요한 내용을 나누고 실습 난이도를 조정했습니다.
- Slack 관리 기능, AI 활용, Workflow 실습을 3일 과정으로 구성했습니다.
- 교육 후 피드백을 수집해 프로그램의 결과를 점검했습니다.

## Result

참가자의 수준과 업무를 반영한 3일 프로그램을 완료했습니다. 교육자료와 실습을 통해 관리·활용 방법을 설명하고 사후 의견을 확인했습니다.

## Lesson

프로그램을 설계할 때는 교육 이후 고객이 수행할 업무를 먼저 확인해야 합니다. 교육 만족도와 이후의 실제 업무 활용은 서로 다른 지표로 점검합니다.
